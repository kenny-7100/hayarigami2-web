## Web 实现

- `engine.ts` 保留 `.text`，增加可选 `Page.spans`、`Page.acquisitions`，以及缓冲 span、样式栈和待呈现收录。2001 的 flags、2013 的 unlocked 继续作为唯一解锁依据，不另设会漂移的收集数据库。
- `text.ts` 在 Unicode 文本规范化时同步映射范围；修剪空白、压缩破折号和换行不会移动高亮。整页教程替换只保留可唯一定位的原文字串样式，不猜译文范围。
- `StoryText.tsx` 供正文与历史共用。新关键词暖金色，已知关键词浅绿色；palette 1 为强调金色，字号换算为相对 em。颜色和幅度是适配现有深绿金色 Web 风格，非 PSP 色表的逐像素复刻。
- 新关键词用 Web Animations 从正文位置移向下方收录标签；多个事件错峰。辞典标签滑入，同段多条分别保留，标签可直接查阅。为触屏与可发现性，标签不自动消失，而保留到换页；快速翻页取消旧动画，不阻塞剧情。
- 「关键词手帖」为 Web 新增的查阅入口，展示已持有的关键词标志；不改变推理候选/答案规则。辞典仍是独立入口。点具体词或收录提示，会将对应条目放在面板最前，其余最近获得者优先。
- 场景不加遮罩，文字、标签、动画终点均在下方阅读区域。`prefers-reduced-motion` 禁止飞行/滑动，但保留高亮、可点击标签及礼貌级读屏通知。
- 初次载入或读档只显示本段信息，不重新播放获得动画；关闭面板、音量改变不会重播。同词再出现有已知色，不再产生收录事件。

## 存档及边界

旧存档没有富文本字段仍可读取，205/206 的旧 adapted 记录继续被接受。新存档校验样式、非重叠范围、已存在的 ID、事件类型及长度；保留 revision 和原有剧情 PC。旧存档历史没有样式元数据，不用猜测补染；继续阅读的新段落正常记录样式。旧档若恰好停在跨页样式栈内部，缺失的旧栈无法精确追溯，恢复默认 Web 样式直到后续源指令重新设置。

目前未移植原版注音排版、逐字打字机、收录原声音效，亦未主张 PSP 逐帧一致。选项仍是原有 Unicode 文本；本次范围为对白/历史及收录反馈。后续章若使用新 palette、在选择标签内部强调或不同字体命令，必须按源调用补齐并回归，不能从“205 已支持”推导全部文本演出已支持。
