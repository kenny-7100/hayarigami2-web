## 交付范围

原版记录 10001–18402 范围内的 371 个剧情/控制记录全部纳入编译；加上序章 4 个记录，共 375 个。Web 端执行原始脚本分支，不使用按物理顺序播放的剧本，不预填正确推理答案。科学路线、灵异路线、错误推理、勇气消耗、自我质问、关键词发现、关系图、确认/返回修改、评分和结局均由 TypeScript 状态机实现。

浏览器只加载 Unicode JSON、PNG、AAC。原版文字编码、XOR、PSP 字库、纹理解码和音频转码全部在离线 Python 工具中处理。React 提供正文、选择按钮、关系图表单、人物说明、术语释义和存档交互。关系图保留原始人物/箭头素材，关键词使用可缩放的 SVG 与原生 HTML select。

本版本资源：65 张背景、66 张角色/界面精灵、28 张关系图纹理、25 首音乐、17 个静态音效、56 个流式音效、13 个循环环境音、3 个附加音轨；43 条术语释义、70 个关键词。资源计数含共享序章素材。

## 资源转换

全局资源表 `0x0887A9CC`；背景映射 `0x0887D9DC`，精灵映射 `0x0887E63C`。纹理支持 PSP 字节布局的 DXT1/3/5、4/8 位调色板、16×8 swizzle、存储行步长与裁剪。图 2 的纹理来自资源 24（`0x0882f864 → 0x08853058`），使用独立命名空间避免与精灵 ID 冲突。

流式音效表 `0x0887FFF4`；静态音效表 `0x08883D64`；循环环境音表 `0x08884178`；附加音乐表 `0x0887FEA0`。静态样本从 `static_se.phd` 的 PPVA 波形表和 `static_se.pbd` 提取，再包装 VAG 转 AAC。资源边界和转码失败会阻止构建。

`chapter-zero-glyph-map.json` 包含离线字形映射。新字符未映射时编译失败。词条正文来自 OccultFile 对应记录 +93 的 XOR 字符串；原生菜单中的解释使用 Unicode。发现的错字按源字形修正，例如 `8bba` 是“胁”，不是“肋”。人工校字仍不等于原汉化全文的语言校勘。

## Web 演出适配

本次完成的是原生 Web 章节，**不是 PSP 逐帧画面复刻**。这些差异是明确的阅读与演出适配：

- 原版逐字等待、行等待、字体/字距/窗口位置由完整对话块、Web 字体、下方正文布局代替；不在 Web 保留 PSP 注音或按钮字形渲染。
- 原版异步预加载/同步屏障由浏览器资源请求处理；音乐淡出用目标音量状态代替逐帧曲线。
- 自我质问使用原生图形背景与 CSS 动效；闪光/震动使用 CSS，并尊重减少动态效果设置。未复刻原版 anm 时间轴及每个过场的逐帧动画。
- 关系图相机平移改为滚动与缩放；原版控制器教程在对应页面替换为网页操作说明。
- 开场 PMF、全游戏鉴赏/CG 收集界面、后续章节不属于本章交付。

保留原始指令与偏移以便继续核对，不将演出适配宣称为原版逐帧一致。
