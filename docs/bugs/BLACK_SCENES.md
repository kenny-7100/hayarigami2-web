# BLACK-SCENES：阅读时画面提前变黑

日期：2026-10-19。状态：已验证。

## 玩家现象与复现

用户提供序章 Friend of a Friend、辞典教学、第零话黑暗天/吉祥天、章题、警视厅介绍五张截图。普通 Chrome 页面继续游戏后确认停在警视厅介绍；复现和测试存读档使用独立 Chrome context `black-scene-investigation`。

确认问题一：从入口 10001 推进 14 次，`10201:67532` 文字显示期间上方全黑。源背景 100 在正文开始时可见，但引擎把本块末尾的下一背景预载结果直接用于整页显示。

确认问题二：从序章入口 1 开始，停留第一句不推进，原动画会运行至全屏黑幕。原主时间线与 Web 慢速阅读脱节。真实浏览器可复现，不是缺图片或 HTTP 404。

## 修复与证据

代码在 engine.ts、scene.ts、AnimationScene.tsx、animation.ts 和 App.tsx。段内背景替换保留独立阅读快照；快照只在最终背景全不可见时使用。存档可选字段通过资源/数值校验，旧警视厅存档用已核对的直线开场重算图层。序章 100:1 的主淡黑时间线跟随剧情等待，子动画仍运动。

具体源偏移、处理器地址与 SHA-256 见 [SCENE_RENDERING](../SCENE_RENDERING.md)。没有修改源镜像、编译文本、脚本指令索引或 revision。未添加占位背景。

- 场景/动画专项 13 项通过：从真实第零话入口到警视厅、下一段地下五层、新旧存档往返、损坏阅读图层拒绝、原暗场保留、慢速阅读 6000 帧不误触黑幕、子动画持续变化、第一话倒杆背景与随后撞击暗场。
- Chrome 桌面、360×740、440×956、844×390 实际观察外景，检查继续按钮、正文布局；键盘空格和点击继续进入地下五层及办公室。
- 独立 context 的空手动槽保存旧格式警视厅检查点，推进后读取，恢复同一正文与外景；正式 `/zh-Hans/` 读取该手动槽、刷新、继续自动存档后也恢复相同外景。
- 序章第一句实际停留超过 120 秒，车内和路灯仍可见，路灯位置持续变化。
- 42 条现有路线额外重放，背景快照实际影响两个页面：警视厅与第一话 `20756:1627476`。后者从灵异真实路线生成检查点，Chrome 实际显示背景 1298；推进后仍为源撞击暗场。没有把这些额外重放称为全旗标组合覆盖。
- 其余四张截图按源证据保留暗场；Friend of a Friend 的动画黑幕不是纹理遗漏。辞典教学、黑暗天开场、章题没有源背景可补。
