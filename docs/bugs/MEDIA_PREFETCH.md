# MEDIA-PREFETCH：图片与声音网络等待

日期：2026-10-19。玩家反馈背景不能及时显示、声音开始播放滞后。

## 根因与修复

原先 SVG 图片在切换场景后才请求，动画组件挂载后才下载图集；BGM/循环音轨使用 `preload="none"`，一次性音效在定时器触发时才创建 Audio。慢网络会使正文已经推进，但图片/声音仍等待下载。

新增 `src/game/media-plan.ts`、`media.ts`、`useMediaState.ts`：

- 根据当前显示背景（含 readingLayers）、可见立绘、完整动画图集、关系图素材及全部声音通道列出当前必需媒体。
- 阅读期间在独立状态副本上预演后续停顿，深度最多 4、总计最多 12 个状态，分支只预演当前合法选项。清空副本历史以控制成本；不自动选择真实路线、不写入存档，不修改旗标、勇气或随机数。姓名输入、推理等不能预测的交互留到提交后处理。
- 每批最多 4 个请求，复用正在加载及完成的资源；前台切换开始后停止旧预取的后续批次，已开始的共享请求继续完成。
- 下载完整 Blob；图片先 decode，音频先通过本地 Blob 的 canplaythrough 检查。SVG、WebGL、BGM、循环音和单次音效均复用缓存，不在播放时重新访问远端媒体。单次音效播放器在安排延迟前创建，保留原脚本 delay。
- 进入章节、读档、继续、选择和推理提交统一经过媒体准备门槛。准备期间保留上一画面/正文，阻止重复推进；成功后才发布状态并触发自动存档。失败显示可重试错误，失败 Promise 不永久缓存。请求超时 45 秒，音频准备超时 15 秒。
- 缓存按最近使用回收，估算 Blob 字节与图片 RGBA 解码字节，预算 96 MiB；当前及预取工作集受保护，工作集自身过大时允许超预算。回收释放 Object URL；这不是浏览器/GPU 总内存的硬上限。

不修改原始指令语义或资源，也不新增假背景。网络资源门槛是 Web 展示时机的调整。

## 边界

初次进入、超出预取窗口、跳章或持续断网仍可能等待，不能承诺任意网络下零等待。缓存为页面内存缓存，刷新后的资源是否命中 HTTP 缓存由服务器和浏览器决定，不实现全游戏离线包。96 MiB 不包含所有媒体解码器/GPU内存。音频自动播放策略仍要求玩家开启声音；本轮未验收 Safari、Firefox、实体手机或做声卡输出延迟测量。
