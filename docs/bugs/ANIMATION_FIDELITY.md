# ANIMATION-FIDELITY：动画缺层、缩小与时间线失真

日期：2026-10-19。用户报告序章汽车场景不正确、循环时上下跳动，以及其他动画显示不全。本记录是 BLACK-SCENES 的后续；此前“不提前变黑”的验收不能证明动画还原完整。

## 根因与修改

1. 原 SVG 只读取四角 alpha 的平均值，并按 /128 放大后向下传播，丢弃 RGB。改为保留各角 RGBA，每层执行 `min(255, floor(child * parent / 128))`，最后纹理 alpha 按 /255 混合。GPU 的 RGB 倍增仍保留，不能把默认 RGB=128 当成整体半亮度。
2. 原 512/768 使用 CSS screen/multiply。改为纹理四边形的 `src * alpha + dst` / `dst - src * alpha`，颜色在两三角形间插值，保留四角透明边缘。UV 按原版内缩 1.5 像素，位置与插值保留源整数截断。
3. 所有动画曾统一缩放 640×448 → 480×272。原版的 500、5600、6000、6100、6200、6300、6400 使用屏幕坐标，现明确绕过该转换。5600 图示的脚本 x=114 经 native 转换为屏幕 x=152；没有根据图片尺寸猜缩放。
4. 2406/2407 常在 2403 前设置位置、深度和颜色。旧代码因“动画尚不存在”丢弃设置，再在启动时强制归零。现保留 `animationSettings`，启动继承，2405 清理；新颜色与设置通过存档验证，旧存档没有这些字段仍可读。
5. 序章外层虽已跟随正文，天空的有限子动画仍按墙钟走到终帧。现将整幕故事时钟传递到非循环子动画，循环分支仍独立运行。翻页不把脚本等待帧重复加到循环运动中；隐藏页面和减少动态效果时不累积播放时间。
6. 同类有限整幕演出（100、1700、300、400、6000–6400，以及 1400:10）采用正文/名单卡片推进时钟，避免阅读停顿直接播放到源终止黑场。雨、粒子、自我质问与监控等仍按自己的循环/墙钟播放。这是 Web 整段阅读适配，不冒称原版逐行实时播放。

所有纹理解码完成后才呈现第一帧。纹理失败、未知混合、WebGL 初始化/上下文丢失显式报错，不能静默显示缺层场景。

## 边界

不是 PSP 实机录像逐帧比对，也不宣称硬件整数纹理过滤/色彩精度完全一致。动画内部混合按源公式，动画层与 SVG 背景/人物仍按 Web 合成。上下文丢失当前显式提示刷新恢复。旧存档丢失的历史位置设置不凭空推断，后续脚本重新设置后生效；所有旧存档立即使用新的颜色、坐标模式与故事时钟。源本就存在的黑场、局部图示和汽车轻微颠簸保留。
