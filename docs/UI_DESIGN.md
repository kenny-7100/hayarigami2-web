# 游戏界面设计约束

2026-10-19。保留深绿、金色和衬线字的悬疑阅读风格；布局以原画、正文和实际游戏操作为核心。

## 信息与布局

- 标题页原图完整等比展示，菜单独立排布。桌面左右分区，手机上下分区，不把菜单叠在图上。
- 首页只提供继续、序章、章节选择及语言、声音、存档、设置。九章选择以本篇/人物篇分组在弹窗中呈现，不嵌套滚动列表。
- 阅读时场景在上，正文在下；原图不附加暗罩。场景 SVG 保持原始镜头几何，长运镜图不能改成全图缩放。
- 场景、正文和工具栏共用响应式宽度，最大 1100px，左右边界一致。桌面继续按钮与正文顶部对齐；手机及矮横屏将继续放在正文上方独立右侧操作行，位置不随正文高度变化。长文本、选项允许页面自然滚动，不固定高度裁切。
- 存档位显示章节与时间，不显示脚本位置、段落计数。设置只包含字号、音量、声音和操作说明。
- 片尾卡片横跨正文列；结章页不再保留空白舞台，直接显示结果、下一章、重玩和返回标题。
- 错误详细信息保留在控制台，界面显示可理解的失败提示。开发命令、资源统计和 QA 检查点不得进入正式页面。

## 响应式与交互

- 700px 以下使用手机布局；高度 500px 以下的横屏压缩场景与间距，但不缩小触控按钮。
- 普通按钮至少 44px 高；正文内联关键词保持文本行内布局。手机推理下拉框使用 16px 字号，避免小字号引发输入放大。
- 弹窗采用固定标题/关闭按钮及单一内容滚动区，适配安全区。Escape 关闭并恢复触发按钮焦点。
- 推理图保留缩放、查看全图及列表选择；当前编辑关系有持续高亮，取消提交不丢答案。
- 金色只用于主操作、关键词和选中状态；不添加宣传标签、伪档案编号、装饰性英文或无关动画。
- 保留关键词高亮与收录反馈，并尊重 prefers-reduced-motion。

## 查阅与焦点（玩家抽样评审补充）

- 辞典和关键词只搜索已发现内容；历史只搜索已读内容。先匹配全部已读记录，再分页显示，不能只搜已渲染的 100 段。
- 搜索匹配显示语言，兼容全角/半角、大小写和空格分词；保留原文，不用搜索归一化改写剧情。空结果和清除操作必须有本地化反馈。
- 点击新收录词清除旧查询、定位并突出该词；从工具栏重新打开时清除定位与查询。搜索框在长面板中保持可达。
- 图上人物说明出现后进入可见区域，关闭/Escape 回到原人物；点关系进入关键词编辑器。只读关系不伪装成可编辑按钮。
- 面板和确认框阻止背景滚动，并保持双向 Tab 循环。关闭后恢复触发控件；搜索框中 Esc 优先清空查询，再按一次关闭面板。
- 存读档通知使用顶栏下的文档流区域，不以底部浮层遮挡“继续”或“完成整理”。
- 姓名错误关联输入框并在重新编辑时清除；输入方向自动判断，不使用拼写检查纠正人名。
