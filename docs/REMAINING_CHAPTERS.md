## 新指令与原版证据

EBOOT 地址依据当前镜像；文件偏移使用 `address - 0x08803FAC`。

- **101**：目标由两个 u16 拼成 u32。70001/90001 及 68301/68302 等跳转不能截断为低 16 位。
- **1301 / 1302**：原处理器 08820838 创建演出任务；08820920 等待任务。实际章节目标仅 5004、6101–6136、6200–6225，任务额外参数全零。Web 同步执行这些明确审计的演出脚本，以调用栈恢复主脚本；名单卡片变为可保存、可手动继续和跳过的阅读停顿。未审计的目标或参数报错。不是 PSP 并发任务时间线的逐帧复刻。
- **1304**：08820A04 调用 08831410。1000 个原始随机数位于 08882500；结果为 table[index] % bound，index=(index+bound)%1000，写入指定变量。由香篇使用 bound=10、变量 2。索引写入存档，读档重现同一分支；新开始用浏览器随机数选择初始索引。测试覆盖表中全部 1000 个索引。
- **1006**：088202F8 进入 PSP 系统存档。Web 的原始 1310 保存询问继续运行分支后打开 IndexedDB 存档面板；“暂不手动保存”仍保留应用一贯的自动存档。与推理确认的“继续修改/确认提交”分开。
- **1312 / 1314**：08820F80 / 088210B0 设置原生输入全局位 6/7。Web 没有 PSP 的自动跳读任务，保持现有按钮/键盘交互。
- **1313**：08820FF8–088210AC 取消当前任务以外的演出任务。Web 的子脚本已同步结束，跳过片尾清空调用栈和名单卡片后执行原版 6099/7099 跳过脚本。

新增状态 `chapterEntry/randomIndex/callStack/creditLines` 有存档校验；旧存档按所在章节推断归属。普通翻页共享不可变历史页，避免每段深拷贝全部历史；存档校验按脚本缓存正文块合法偏移。测试检查翻页不修改旧快照。历史上限提升到 50000 段，支持完整跨章阅读。

## 严格绑定的原版资源例外

- source 37212，offset 2516644，动画 1:2152：088614B0–C0 在未匹配变体时选择原表第一行，故明确别名到 1:0；保留 variantFallbacks 元数据。
- 动画 6200 第 8 个 cell：原数据 `(texture=16,palette=1,blend=0,flip=0,u=0,v=0,w=480,h=272)`，包只有 6 个纹理。088627D8–E4 的描述符访问落在表外，实际描述符宽高为 0；该 cell 用于终止黑色帧（42/53）。编译器只在这组精确条件及描述符零宽高下将 cell 记为无绘制，其他非法纹理仍失败。这一异常不能声称与非法 PSP 采样逐像素一致。
- ambient 120/349：342 项原表 0887FFF4 中不存在；088657D0 调 lookup 08864C10，088657DC 在空返回时退出。
- loop 601：原表 08884178–088847A8 中不存在；lookup 0883D64C 返回空，调用方 0883D4AC–C0 不播放并返回。
- music 968：source 43406，offset 3369420；0886529C–B8 明确拒绝 `<1` 或 `>=53` 的 ID。Web 保留之前音乐，不把无效 ID 当成停止音乐。

以上不是通用“缺资源就忽略”：编译器对新的未审计缺项抛错。

## 复现

```sh
npm run prepare:game
npm run verify
node --experimental-strip-types tests/generate-remaining-browser-fixtures.mjs
# 独立测试窗口：/tests/qa.html?bundle=all-chapters
npm run qa:replay -- --route tests/fixtures/chapter-3-finale.json --bundle all-finale --check-saves
```

`replay_route` 支持单条明确的 `previousRoute` 前置通关轨迹，以及 `randomIndex`；缺选择、错位置、少答案、结局/分数不符即失败。每章完整路线测试逐停顿做完整历史 JSON 往返；浏览器夹具只保留 100 页，不能替代该测试。

探索工具 `discover-remaining-routes.mjs`、`optimize-remaining-routes.mjs`、`discover-final-sequence.mjs`、`build-remaining-corpus.mjs` 不属于生产程序。优化器只搜索测试答案，绝不导入运行时。构建覆盖集依赖 output 中探索结果；日常测试只需要已固化的 tests/fixtures。探索生成的路线必须经过严格重放后才能纳入回归。

## 适配边界

这次完成的是所有章节的 Web 剧情、选择、推理、评分、辞典、存档、原资源演出与结局闭环。PSP 系统菜单/鉴赏壳不作为章节游戏逻辑移入；原生名单并发演出改为手动卡片，原版混色仍沿用已记录的 Web 近似，不声称逐帧/逐像素一致。未新增中文翻译。Safari、Firefox、实体移动设备尚未作设备验收。
