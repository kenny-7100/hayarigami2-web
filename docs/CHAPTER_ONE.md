## 文字处理：不新增翻译

镜像自身并非全日文：记录 20101 的开场及本章关键词已有中文。保留这些既有译文，其余正文、关系说明与辞典保持日文，不做新翻译。

日文原始字节仅在 Python 编译阶段以严格 CP932 加经源字形验证的特殊映射转换。姓名控制字转为普通 Unicode 模板；原版自定义字形 8789 为“鬼”，不能直接采用 CP932 的“㊨”。中文增补映射记录于 scripts/data/chapter-one-glyph-map.json，包含“孪”等经字形复核的字符。浏览器只接收 Unicode，使用网页字体和日文换行规则，不包含 PSP 字库或文本解码器。
