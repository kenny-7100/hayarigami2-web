## 范围

## 已建立的架构

- `src/i18n/locale.ts`：浏览器语言区域归一化；URL > 保存选择 > 浏览器语言列表 > 英语。明确的 URL 不被浏览器偏好覆盖。
- `store.ts` / `useLocale.ts`：原生 History API 切换，保留 query/hash；更新 document.lang/dir，记忆选择，监听 popstate。QA 路径使用 lang 查询参数。
- `LanguagePicker.tsx`：顶部原生 select，19 个选项用本语言名称；与既有深绿/金色风格一致。
- `localization/ui/*.json`：目前每个版本 129 条基础界面文本；语言控件的无障碍名称也使用目标语言，选项保持语言自称。以完整句子和命名占位符代替语序拼接。这里的条目数不是全游戏翻译完成度。
- `localization/story/*.json`：按语言异步加载；章节、辞典、关键词、关系说明与富文本段落单独映射，源指纹与源正文必须匹配。
- `richText.ts` / `gameCatalog.ts`：姓名、关键词、强调结构独立记录；译文可调整语序，不能丢失或重复必需引用。原始剧情/存档仍保存原文和游戏状态。旧页只在完整原文匹配时使用对应译文。
- `names.ts`：Web 姓名允许 1–32 个字素，额外限制原始长度，允许字形连接符，拒绝控制/双向覆盖字符。原版指令自身的参数不改。
- RTL 不镜像场景 SVG、图像或推理图几何。推理图长标签简略显示，完整标签仍在 title、无障碍名称及编辑选择中。

## 静态部署的语言深链接

目前应用部署在域名根目录。`/en/`、`/ar/` 等页面请求必须回退至 `index.html`，游戏和构建资源仍走 `/game/` 与 `/assets/` 的实际文件。不能把缺失的 JSON、图片或音频也重写成 HTML。Nginx 可对页面位置使用 `try_files $uri $uri/ /index.html`，并为 `/game/`、`/assets/` 单设 `try_files $uri =404`。Vite 开发服务器已实际验证语言路径刷新。

子目录托管尚未适配：当前语言 URL 从根路径生成，不能仅修改 Vite `base` 后就宣称支持 `/some-prefix/en/`。生产部署验收需要实际托管环境，不把开发服务器的 SPA 回退当作所有平台的验证。

## 本轮新增验收保护

- 发布检查显式列出未闭合的源片段对应关系及图片文字清单缺口；即使现有路线全部译完，也不能提前通过发布检查。
- 片尾标签以 `label.<原文>` 和原始指令位置双重收录，避免 UI 实际查找键与翻译库存键不一致。
- 旧选项兼容完整原文匹配；旧页候选按段落缓存，避免历史面板逐页扫描全包。
- 语言包显示前校验结构、源指纹、键及富文本引用；损坏时显示可重试提示。
- 语言 store 测试涵盖 URL 优先、初始化幂等、后退、订阅取消及 localStorage 写入失败。
- 已翻译正文方向取目标语言，姓名独立隔离，避免以拉丁或中文姓名开头的 RTL 段落误判方向。勇气、得分、音量使用 Intl 数字格式。
- 新增批次与无效文本回归后，i18n 单独测试为 14 项通过；拒绝意外双向覆盖符、替代字符及把必要高亮引用替换成空串，仍允许文字塑形连接符。

## 后续场景离线批次

```sh
node --experimental-strip-types scripts/localization_batch.mjs export --locale en --route chapter-zero-science-success --limit 20 --file output/localization/next-en.json
# 阅读 source、text、context，逐段手工填写 parts，疑点写 translatorNotes。
node --experimental-strip-types scripts/localization_batch.mjs import --locale en --file output/localization/next-en.json
node --experimental-strip-types --test tests/i18n.test.mjs
npm run i18n:check
```

导出文件已存在时拒绝覆盖。导入只写 draft，不自动审校，不调用 API。已有译文的修订应显式编辑和审校，不能用批次导入静默覆盖。路线去重后同一段可能归属于较早采集路线；批次 route 表示采集上下文，不是全部可到达该段的路线集合。
