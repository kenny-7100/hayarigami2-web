# 已验证的排错经验

## 图片不完整 / 黑屏

先从正文对应记录、停顿时 state 定位，不要先改 CSS cover/contain。用审计的 script/pc/offset 关联原始指令；检查以下顺序：

1. PNG 是否存在，元数据是否保留原始宽高。背景 105 为480×664且 y=-380，不能先压成480×272再移动，否则完全离开视口。
2. 看原脚本显式尺寸和符号。406 使用有符号宽高；(-640,-440)不能按约6.5万处理；旧存档的无符号值仍需兼容。
3. 看外层相机的实际尺寸与裁剪。仅viewBox正确不够，宽SVG与max-height可让相机外像素进入侧边；外层保持480:272。
4. 图像节点依脚本尺寸渲染，避免每张SVG image额外meet产生留边。首页完整海报、剧情运镜背景、关系图总览是三个不同缩放需求。
5. 背景/立绘 alpha 是否已经清零？是否存在可见动画？雨刷、隧道、监控和行车的完整画面由动画提供，不能只绘背景表。
6. 如果源脚本清空所有层且无动画，这是真正暗场。如10201偏移69876的403；不能为了“每页都有图”随意保留上一张。
7. 正文按完整对话块发布，块内演出可能已推进；若场景与文字不符，检查publish之前的指令时序，不草率认定素材丢失。

## 动画

- 包资源映射、9张表、父子时间轴等证据在SCENE_RENDERING。新增动画要检查变体、纹理、调色板、child/sibling、嵌套命令和循环/停留，不把解出一张PNG当作完成。
- 父节点停在0帧不代表子动画停止。采样0/60/180等多个时间，比较实际draws。
- 普通翻页不应销毁整棵SVG；按audioSequence改key会重启动画。需把场景生命周期和闪光/震动触发分开。
- 当前混色有近似，未与PSP逐帧比对。彩色监控噪声不能仅凭主观观感改调色板，也不能把近似说成原版完全一致。

## 文本

- 汉化用私有码表；CP932“能解码”不代表文字正确。8789按标准可能得到㊨，实际源字形是鬼。
- 不同资料可能混用中文映射与日文。第一话20101和关键词已有汉化，正文/释义多数日文。
- 保留text fragment首尾空白，不能对每片段无条件strip，否则拼接错字距。
- 名字在正文与辞典可能通过不同控制码插入，均转Web占位符；原始字节只留离线。

## 控制流与覆盖

- 指令第二字节是实际长度，非统一4字节对齐；边界错误会把文本当opcode。
- 先识别无条件跳转再解释后续代码。第一话203处静态选择中只有202处可达，唯一例外有具体前置跳转证据。
- compare modes、signed变量、饱和值、勇气消耗、答案候选flag都必须按原始语义处理。未知模式明确失败。
- 原始注册表181处理器不等于全部Web已支持。静态“新指令差集为空”也不说明新参数/资源可运行。
- 101原始目标是uint32；后续高ID不能只用args[0]。新增包检查专门检测此风险。

## Web交互与存档

- 原生dialog处于top layer，外部z-index再高也不能盖住它。通知应在面板内；关闭标题固定，正文独立滚动。
- 长历史一次渲染数千段且从第一段开始，既慢又不好回看。当前最近记录优先，每批100段；存档仍保留完整历史。
- 手机选择页无需正文120px最低留白；短横屏不能沿用场景260px最低高度。
- 关系图默认先适配宽高看全貌，再提供放大、滚动和下拉列表。小人物和关系字段要有可访问名称。
- 点击继续后焦点仍在button；过滤所有button键盘事件会导致右方向键失效。保留输入/select原生按键行为。
- Reader自动保存每个有效停顿；QA页同样如此。独立无痕与普通窗口隔离，但多个无痕窗口可能共享一个临时数据库。
- 字号/音量localStorage与游戏IndexedDB是两类持久化；二者都要测刷新，但不要自动恢复声音播放手势。

## 资源缓存与发布

源文件存在、PNG尺寸正确不代表新算法输出已生效。当前texture/music按目标存在复用；调整解码后记录受影响文件并重建它们。不要删除ISO或玩家数据来“清缓存”。打包后确认tests/QA/答案/反汇编未被生产入口引用；只要仍使用根index.html，开发验收页不会自动成为生产页面。

## 手动反馈与跨浏览器

- 玩家只给中文台词时，先 `qa:bug locate`，不要全文输出大型目录或据章节名推断脚本范围。同句多路线出现时结合上下文，pageStartPc 不等于停顿 pc。
- QA 检查点是候选，不是玩家现场；复制已知检查点后实际操作复现才能确认根因。全历史存档问题不能使用截短 UI 历史证明修复。
- Safari 原生 range 默认横向 margin 与 width:100% 可叠加溢出；先检查实际盒模型，明确 margin 与 flex 最小宽度，不能简单 overflow-x:hidden 掩盖内容。
- 浏览器辅助功能树没有列出 dialog 子节点，不一定是页面未显示；截图和实际键盘/鼠标操作需互相核对。开发工具连接失败时不得伪称控制台无错误。
- 当前状态优先于历史验收中的“尚未翻译/未测试”句子；记录代码、游戏和翻译三个版本，避免用“同一个 game.json”推定 UI 与译文也一致。
