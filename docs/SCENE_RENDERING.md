# 背景裁剪与动画场景修复

2026-10-19。针对用户提供的第零话截图，扩展检查第零话及第一话。

## 背景问题

10201 的“阴暗的房间里没有窗户”使用背景 110，源纹理 608×320，脚本移动到 (-120,0)。旧渲染器先压缩为 480×272 再平移，导致额外空边。现在编译 backgroundTextures 原始尺寸，按源像素坐标放置，再由统一 480×272 相机裁切。

“灰色的书架上摆满了”使用背景 115，脚本明确缩放为 480×280。之前每个 SVG image 自己等比适配，产生非脚本要求的留边。现在严格使用指定尺寸。SVG 外层本身也保持 480:272，避免宽画布中的相机外内容漏到两侧留白。

“我的办公室位于它的地下５层”使用 480×664 的纵向背景 105，移动到 y=-380。旧渲染器把高度变成 272，导致整个图片在视口外；现已恢复可见的办公室门。

406 原始处理器 0x0881D3CC 使用有符号 lh 读取宽高，0x08816D50 保留源尺寸与缩放状态。第一话 20756 使用 (-640,-440) 翻转背景；之前按无符号解释为约 6.5 万像素。现支持带符号尺寸，旧存档的无符号值也在渲染时兼容转换。

大背景用于原版运镜，因此呈现的是源脚本指定的相机画面，不将整张长图强行缩成一张图。外部留白用于维持相机比例；窄屏场景不再纵向撑满而将继续按钮挤到屏外。

## 暗场与缺失动画的区别

第三张截图正文“可是……我不知道那是否真的就是『不存在的事』”位于 10201。偏移 69876 的 403 将最后一个可见背景槽 2 设为透明，之前其他槽已关闭；没有可见精灵或活动动画。此处保留原脚本暗场，去掉 Web 自行添加的绿色渐变。

另有真实遗漏：旧版只记录动画状态，除自我质问 CSS 替代外没有渲染动画。雨天车内 200、隧道 600、监控 700、白天行车 1000 等依赖动画提供整个场景，因此会空白。本次新增离线动画编译与原生 Web 动画采样/渲染，覆盖当前生产脚本调用的 14 个动画 ID/变体组合及其子动画。

## 逆向证据与实现

- 0x08852D7C：动画包资源映射；100→2、200→3、600→7、700→8、1000→9、1700→12、5400→13。基础动画来自 anm0000.dat。
- 每包 16 字节头，后跟带长度的动画块。块内九组表：变体、树节点、关键帧、调色板描述、纹理描述、图块、变换、顶点颜色、子动画命令。
- 0x088621DC：节点 child/sibling；0x0886257C：按时间选择关键帧；0x08862680：图块、位置、中心、旋转、百分比缩放与顶点颜色。
- 0x08861F54 / 0x08864564：子动画启动、起始时间及取消；父动画停在零帧时子动画仍继续播放。
- 0x08861C10：1 为循环起点、2/3 回环、4/5 停留。Web 使用帧采样与 requestAnimationFrame。
- 动画素材采用 640×448 设计坐标映射到场景相机；图块从源调色板纹理离线转换，Web 用 SVG 嵌套视口裁切，并按层序组合。没有模拟 PSP CPU，也没有加载 PSP 字库。

动画的循环、子动画、纹理、移动、缩放、旋转和透明度均有 Web 实现。颜色与混合仍有明确的适配边界：顶点透明度采用平均值，512/768 混合映射为 Web screen/multiply；未声称 PSP 像素级混合一致。正文继续按完整对话块阅读，原版各行之间的演出节拍未逐帧复刻。
