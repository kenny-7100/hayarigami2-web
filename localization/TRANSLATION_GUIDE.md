# 流行之神 2：本地化与翻译审校规范

状态：工作规范与验收门槛，不表示任何语言已经全文翻译完成。2026-10-19 用户已授权翻译全部内容；此前“未译日文暂不翻译”的限制已被本次要求取代。已确认 18 种产品语言：中文、英语、印地语、西班牙语、法语、阿拉伯语、孟加拉语、葡萄牙语、俄语、印尼语、乌尔都语、德语、日语、马拉地语、越南语、泰卢固语、土耳其语、泰米尔语。中文含简繁，共 19 个 locale。

## 叙事原则

本作是以日本警察调查为框架的都市怪谈。保留怀疑、恐惧与科学/灵异解释之间的张力。旁白克制、具体，不为营造恐怖自行增加血腥、神秘暗示或结论。对话自然，但不换成当代网络梗，不把不同人物都译成同一种声音。

- 先读一个连续场景及其进入/离开分支，再译完整对白或段落。脚本指令切开的字符片段不是翻译单元。
- 对照相邻对白、人物说明、已知关系与分支条件判断说话人、代词和语气。无法确定时记录疑点，不以猜测写入已审校包。
- 不泄露后续身份和反转。科学路线中的推测不能译成确定事实；灵异路线中的含混也不能被解释性补写抹去。
- 冷幽默、口头禅、敬语、社会距离和方言以目标语言自然表达；不硬套另一国家地域口音或族群刻板印象。
- 警衔、机构、学校、民俗、仪式与超自然名词先列术语表；保留日本背景，不改写成目的地国家的警察制度。
- 既有汉化不是无条件正确的母本。发现乱码、人物误名或意义矛盾须结合可用日文上下文/原始证据确认，保留修订记录。没有日文原文的段落不能称为恢复了日文原作。
- 人物名、称呼、警衔、地名、核心怪谈名在正文、关键词、选项、辞典、关系说明之间一致。需要区别真名/别称/身份伪装时明确记录语境。
- 选项保留原有信息量、行动意图与语气强弱，不用译文暗示正确答案或改变勇气消耗含义。
- 辞典是解说文体，与角色对白区分。医学/历史/民俗说法忠实呈现游戏原文，不暗中以当代知识改写剧情。

## 文本结构与标记

1. 原始脚本 ID、偏移、选择索引、关键词 ID、剧情旗标及条件永不因翻译改变。
2. 人名插值使用命名占位符，不硬编码默认玩家姓名。译文可调整占位符位置，但不能缺失或复制。
3. 关键词和样式标记必须结构化保留。关键词可按目标语调整语序，不靠字符串猜测寻找高亮范围；同词多次出现时不能误标。
4. 句内原 PSP 换行不应强制继承为目标语行宽；语义分段保留。引号、破折号、省略号和数字格式遵循目标语言习惯。
5. 不把姓名和纯数字 ID 当作漏译，也不把原文回退当作已完成翻译。统计“已有译文”“已审校”“沿用原文的说明”分别计数。
6. 所有翻译条目绑定稳定 key 和 sourceHash；原文变化必须标记过期，禁止静默复用。
7. 不使用 HTML 字符串插入译文，不允许译文携带脚本、链接执行逻辑或改写游戏控制流。
8. 图片中的文字单列媒体本地化清单；不以“正文全覆盖”声称图片文字也已翻译。

## 每种语言的交付门槛

- UI、错误提示、无障碍标签、章节名、剧情、选项、片尾、辞典、关键词、人物与关系说明无未解释漏项。
- 自动校验缺项、重复 key、原文指纹、占位符、关键词结构、空译文、Unicode 替代字符及意外双向控制符。
- 同一人物/术语跨章复核；逐场景审校，科学/灵异路线及各结局上下文核对。自动化通过不是文学质量通过。
- 读取旧存档、历史文本、正在显示的选项与推理说明能切换语言；旗标、随机状态、关系答案和存档位置不变。
- URL、刷新、前进/后退、浏览器语言识别、手动选择记忆、存储不可用、未知语言代码、资源失败与重试均有测试。
- 桌面、360×740、440×956、844×390、大字号、长词/扩展文本以及阿拉伯语/乌尔都语 RTL 实际走查。
- RTL 只改变界面阅读方向，不镜像原画、推理关系拓扑或叙事镜头；姓名/数字/混合方向片段隔离。箭头按动作含义决定方向，音量和媒体几何不盲目翻转。
- 键盘和屏幕阅读器顺序合理，语言选择项以本语言名称显示，document.lang/dir 与内容相符。字体须覆盖对应文字，不按拉丁字母的字符数截断南亚文字。
- 审校者、日期、未解决疑点及实际设备覆盖留档；不宣称“完美”或“母语审校”而没有对应证据。
